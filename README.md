# LALITA JEWELLERS — Fine South Indian Jewellery, Palani, Tamil Nadu

A complete, premium, production-quality frontend demo website for **Lalita Jewellers**, situated in the temple city of Palani, Tamil Nadu. Built with React, Tailwind CSS, Lucide React, and celebrating timeless South Indian temple jewellery craftsmanship.

![Lalita Jewellers](public/images/bridal-feature.jpg)

---

## 🌟 Key Features

1. **Live Gold & Silver Rate Marquee (Palani Benchmark)**:
   - Real-time animated ticker showing 22K (1g), 24K (1g), 1 Pavun (8g Sovereign), and Pure Silver rates.
   - BIS 916 Hallmark & ISO 9001:2015 trust badges.

2. **Interactive Gold Rate Calculator & Weight Estimator**:
   - Purity selector (22K Gold, 24K Gold, Pure Silver).
   - Grams and Sovereign presets (1g, 4g, 8g / 1 Pavun, 16g, 24g, 40g Bridal).
   - Itemized breakdown of base metal price, wastage / making charges (VA ~9%), and 3% GST.
   - Direct WhatsApp enquiry action with pre-filled weight calculation.

3. **20+ Authentic Traditional Designs with High-Res Imagery**:
   - **Vel & Sacred Dollars**: Palani Murugan Vel Dollar, Temple Kavacham Amulet.
   - **Necklaces & Harams**: Lakshmi Heritage Kasu Mala, Thanjavur Royal Peacock Haram, Ruby Temple Choker, South Sea Pearl Choker.
   - **Bridal Suites**: Grand Muhurtham Oddiyanam (Waist Belt), Royal Kemp Vanki (Armlet), Bridal Mangalsutra & Thali Chain.
   - **Bangles & Kadas**: Twisted Gold Valayal Pair, Men's Singam-Mugam Kada, Silver Baby Bangles.
   - **Silver Heritage**: Handcrafted Bridal Kaal Thandai (Anklets), Auspicious Silver Metti, Mahameru Sri Yantra, Kuthu Vilakku.
   - **Rings & Solitaires**: Celestial Navaratna Ring, Solitaire Diamond Ring.

4. **Bilingual Experience (English / தமிழ்)**:
   - Instant language toggle in the navbar switching titles, categories, and labels between English and Tamil.

5. **Modern 2-Column Mobile App UI**:
   - 2-column e-commerce grid on mobile devices (`grid-cols-2`).
   - Swipable horizontal category filter pills.
   - Fixed bottom mobile app navigation bar (`Home`, `Designs`, `Search`, `Saved`, `Enquiry Bag`).
   - Floating quick contact hub (`WhatsApp` + `Call / Consultation` + `Scroll to Top`).

6. **Interactive Drawers & Modals**:
   - Quick View Modal with specifications, purity details, and care guide.
   - Instant Search Modal with live search across categories and motifs.
   - Wishlist Drawer with localStorage persistence.
   - Demo Enquiry Bag Drawer.
   - Bespoke Bridal Consultation Booking Modal.
   - Customer Reviews Section with category filtering and interactive review submission.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Typography**: Playfair Display (Serif) + Inter (Sans)
- **Palette**: Warm Ivory (`#FAF7F0`), Champagne Gold (`#C6A15B`), Deep Maroon (`#651D32`), Rich Charcoal (`#25211D`)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/sivapragadheeswarii/lalitha.git

# Navigate to the project directory
cd lalitha

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be live at `http://localhost:5173/`.

### Production Build
```bash
npm run build
```
